## Context

2026-08-02 审查（详见 [test-infrastructure 计划](2026-08-02-test-infrastructure.md) 背景）定级的 P0 安全问题：

1. **诊断遥测无鉴权泄漏**：`main.py` 把 `diagnostics/` 以 StaticFiles 无鉴权挂载（index.json 含全量用户 query + conversation_id）；更严重的是 `app/api/diagnostics.py` 的 5 个端点**全部无 `get_current_user` 依赖**，其中 `/diag/chunks?ids=...` 无视 visibility 导出任意 chunk 文本。与 IDOR 组成攻击链：拖 index.json → 拿 conversation_id → 注入他人会话。
2. **会话 IDOR**：`conversation_memory.get_or_create_conversation` 只按 conversation_id 查、不校验 owner → 任意登录用户可向他人会话写入消息、并把他人 history+summary 注入自己的 prompt。
3. **银联卡漏报**：`cn_bank_card` 正则 `\b[1-5]\d{14,18}\b` 不覆盖 6 开头卡段（中国大陆发卡以 62 银联为主）。同时 `mask_text` 对多规则重叠命中（18 位证件号可同时过 id_card 与 bank_card）不做区间去重，偏移累加后输出错乱。
4. **白名单永久开洞**：`whitelist_pii_alert` 把 `alert.matched_text[:20]`（真实 PII 值）写进规则 `exclusion_words` → 该值全网永久免检。

附加中危（同子系统、改动小，一并处理）：登录 `if not user or not verify(...)` 短路造成时序侧信道（可枚举用户名）；`/register` 无限流可批量灌号。

## Design

- **诊断收口**：5 个 diag 端点统一加 `Depends(get_current_user)` + `require_admin`（遥测含所有用户的 query，非 admin 不可见）；删除 `main.py` 的 `/diagnostics` 与 `/tools` 两个静态挂载（`/diag/chunks` 的 chunk 导出同样只留给 admin）。`tools/diagnostics.html` 查看器改为从磁盘打开、走鉴权 API——查看器自身的 token 支持留待后续（见 NOT doing）。
- **会话所有权**：`get_or_create_conversation` 命中已有会话时校验 `conv.user_id == user_id`，不匹配则**静默新建**（不回 404，避免泄露"该会话存在"）。
- **PII 增量**：按 CLAUDE.md "5 条默认规则不可改、可新增" 约束，新增 `cn_bank_card_unionpay`（`6[02589]\d{14,17}`，16–19 位，复用 Luhn 校验）。`mask_text` 在替换循环中记录已处理区间，与已掩码区间重叠的 finding 整体跳过——消除偏移错乱。
- **白名单语义变更**：`whitelist_pii_alert` 不再写 `exclusion_words`，行为收敛为"标记 false_positive + 释放 hold"（与 `false_positive_pii_alert` 同语义，保留端点兼容前端）；`exclusion_words` 定位为"上下文关键词"，只能经规则管理接口编辑。
- **登录时序**：user 不存在时对固定假哈希跑一次 `verify_password`，拉平两条路径的耗时。
- **注册限流**：复用 `_check_rate_limit`，独立桶前缀 `register:`。

### 错误路径枚举

| 场景 | 修复前 | 修复后 |
|---|---|---|

```python
"""PII P0：银联卡检测（6 开头卡段）+ 多规则重叠命中掩码去重。"""
from app.core.pii_rules import validate_bank_card
from app.core.pii_scanner import _partial_mask, mask_text, scan


def _luhn_check_digit(partial: str) -> str:
    """计算使 partial+digit 通过 Luhn 的校验位。"""
    total = 0
    for i, ch in enumerate(reversed(partial)):
        d = int(ch)
        if i % 2 == 0:      # 完整卡号中奇数位（校验位为第 0 位）
            d *= 2
            if d > 9:
                d -= 9
        total += d
    return str((10 - total % 10) % 10)


UNIONPAY = "6217000000000000" + _luhn_check_digit("6217000000000000")  # 16 位 62 开头


def test_unionpay_number_is_luhn_valid():
    assert UNIONPAY.startswith("62") and len(UNIONPAY) == 16
    assert validate_bank_card(UNIONPAY)


def test_unionpay_detected_and_masked():
    text = "付款卡号 %s 请核对" % UNIONPAY
    findings = scan(text)
    rules = {f.rule_name for f in findings}
    assert "cn_bank_card_unionpay" in rules
    masked = mask_text(text, findings=findings)
    assert UNIONPAY not in masked
    assert _partial_mask(UNIONPAY) in masked


def _id_card_also_luhn_valid() -> str:
    """穷举出一个同时过 mod-11（身份证）与 Luhn（银行卡）的 18 位数，
    用于复现 id_card + bank_card 双规则重叠命中。"""
    from app.core.pii_rules import validate_id_card
    for tail2 in range(100):
        for check in "0123456789X":
            candidate = "1101051949123100%02d%s" % (tail2, check)
            if validate_id_card(candidate) and validate_bank_card(candidate):
                return candidate
    raise AssertionError("未找到双规则命中的测试号码")


def test_overlapping_findings_masked_once():

    findings = scan(text)
    assert len(findings) >= 2          # 确实被两条规则同时命中

    # 首个区间整体生效、无偏移错乱：结果恰为一次 partial mask
    assert masked == "证件号 %s 存档" % _partial_mask(number)
```

- [ ] **Step 4: `app/core/pii_scanner.py` 的 `mask_text` 增加重叠区间去重**

```python
    result = list(text)
    offset = 0
    masked_spans: list[tuple[int, int]] = []   # 已掩码的原始区间
    for finding in findings:
        if finding.strategy not in ("mask",):
            continue
        # 与已处理区间重叠的 finding 整体跳过：
        # 多规则命中同一段（如 18 位号同时过 id_card 与 bank_card）时，
        # 重复替换会让 offset 累加错乱、输出破损
        if any(not (finding.end <= s or finding.start >= e) for s, e in masked_spans):
            continue
        start = finding.start + offset
        end = finding.end + offset
        if finding.mask_mode == "partial":
            replacement = _partial_mask(finding.matched_text)
        else:
            replacement = "[已脱敏]"
        delta = len(replacement) - (end - start)
        result[start:end] = replacement
        offset += delta
        masked_spans.append((finding.start, finding.end))

    return "".join(result)
```

```python
    安全约束：不得把命中的真实 PII 值写入 exclusion_words——
    那会让该值在全站永久免检。exclusion_words 只承载上下文关键词
    （示例/模板等），经规则管理接口维护。
    """
    require_admin(current_user)
    with get_db_ctx() as session:
        alert = session.query(PiiAlert).filter(PiiAlert.id == alert_id).first()
        if not alert:
            raise HTTPException(status_code=404, detail="Alert not found")

        alert.status = "false_positive"
        alert.resolved_at = utc_now()

        hold = (
            session.query(PiiHold)
            .filter(
                PiiHold.source_type == alert.source_type,
                PiiHold.source_id == alert.source_id,
                PiiHold.status == "pending",
            )
            .first()
        )
        if hold:
            hold.status = "released"
        session.commit()
        return {"ok": True, "alert_id": alert_id, "new_status": "false_positive"}
```

函数不再使用 `invalidate_cache` / `SensitiveRule`，清理文件内因此失效的导入（若无其他引用）。
